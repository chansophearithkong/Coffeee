# Bean & Bloom — HTML Version

This is a standalone HTML/CSS/JavaScript version of the uploaded React/Firebase coffee website.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
- Home, About, Menu, Contact
- Product search and category filters
- Shopping cart
- Demo ACLEDA QR checkout
- Login/register using localStorage
- Admin dashboard with add/edit/delete products
- Responsive mobile layout
- Original coffee images copied from the uploaded project
